# GoForge Web

Публичный статический тренажёр GoForge: 12 стартовых модулей Deep Go, краткая теория, ручное написание Go-кода, подсказки, вопросы для собеседования, локальный прогресс, экспорт/импорт JSON.

## Использование
После включения GitHub Pages сайт будет доступен по адресу https://kulikovroman08.github.io/goforge-web/ .

Настройка: **Settings → Pages → Deploy from a branch → main / (root) → Save**.

Веб-редактор пока не компилирует Go-код и не оценивает ответы автоматически. Прогресс хранится отдельно на каждом устройстве. Для переноса данных используйте экспорт/импорт JSON.

В этом репозитории только публичные статические файлы. Локальный Go runner, закрытые методички и корпоративные материалы здесь не публикуются.
