# GoForge Gym — Go Backend Trainer

Тренажёр для системного изучения Go и подготовки к собеседованиям на Go Backend Developer. Цель — не просто запомнить ответы, а научиться самостоятельно писать код, понимать его поведение, находить ошибки и аргументировать решения в production.

**[Открыть GoForge Gym](https://kulikovroman08.github.io/goforge-web/gym/)** · [Telegram backend / GoForge Trainer](https://github.com/kulikovroman08/goforge-trainer)

Работает на ПК и телефоне, в обычном браузере и как Telegram Mini App через связанный бот.

## Как учиться

1. **Теория:** контракт, устройство Go, примеры, граничные случаи, применение на работе и вопросы интервью.
2. **Тестирование:** вопросы с вариантами и объяснениями. В каталоге обычно 10–15 вопросов на задачу.
3. **Guided Coding — «Научи меня решать»:**
   - Алгоритм — пошаговые состояния данных.
   - Мысль → Go — перевод действий в код с объяснением.
   - Собери план — восстановление последовательности действий.
   - Пропуски — выбор недостающих выражений.
   - Практика — дописать часть функции, исправить баг или решить с нуля.
4. **Самостоятельный код:** редактор, подсказки, эталон и реальные Go-тесты. Для Guided Coding доступны пять последовательных подсказок.
5. **Повторение:** решить упражнение без подсказок, вернуться к сложным вопросам.

Сценарии уже охватывают срезы и backing array, map, Unicode, указатели, рекурсию, сортировки, Two Sum, sliding window, обработку событий и другие задачи. Не у всех 146 задач есть Guided Coding.

## Запуск и проверка

Открой [Gym](https://kulikovroman08.github.io/goforge-web/gym/), выбери задачу и вкладку кода. Прямая ссылка, например: [сумма чисел](https://kulikovroman08.github.io/goforge-web/gym/?task=core-sum&tab=code).

Кнопка «Запустить Go-тесты» после согласия отправляет решение и тест выбранной задачи на официальный Go Playground. GitHub Pages не исполняет Go самостоятельно. Для выполнения нужен интернет; доступность и лимиты Playground не контролируются проектом.

Для локальной работы нужны Git, Go 1.23+ и Node.js:

```bash
git clone https://github.com/kulikovroman08/goforge-web.git
cd goforge-web
node gym/guided-check.cjs
node gym/core-guided-check.cjs
node gym/runner-check.cjs
node gym/core-solutions-check.cjs
```

Отдельная локальная практика:

```bash
cd gym/practice
go test -run '^$' ./...
go test -run '^TestUniqueUsers$' -v
go test -race -run '^TestCounter$' -v
go test -run '^$' -bench BenchmarkBuildLogLine -benchmem
```

В kata.go намеренно оставлены незавершённые решения и ошибки: обычные тесты должны падать, пока ученик не решит соответствующие упражнения. CI проверяет компиляцию пакета, сборку тестовых программ, структуру каталога и учебных сценариев. Эталонные, частичные и ошибочные варианты проверяются в CI; новые Concurrency-решения дополнительно запускаются с race detector.

Браузерный runner не заменяет локальный race detector, benchmark и реальные интеграционные проверки PostgreSQL/Kafka. Учебные backend-зависимости могут быть моделями или fake-реализациями.

## Телефон, Mini App и данные

- Android: сайт можно добавить на главный экран из Chrome.
- Telegram: бот открывает нужную задачу, теорию или тест по deep link. Доступность нового каталога зависит от версии запущенного бота.
- Черновики и прогресс Gym хранятся в localStorage конкретного браузера/WebView. Синхронизации ПК ↔ телефон ↔ бот пока нет.
- Service worker кеширует ресурсы; после обновления при необходимости перезагрузите сайт или полностью закройте и откройте Mini App. Для реальных Go-тестов всё равно нужен интернет.
- Старый Deep Go MVP: https://kulikovroman08.github.io/goforge-web/?legacy=1 — отдельный режим и отдельное хранилище.

## Дорожная карта

План — построить последовательное обучение Go Backend от Beginner до Senior: сначала понять устройство языка, затем научиться писать код самостоятельно, после этого решать производственные задачи и объяснять инженерные решения на интервью.

| Этап | Содержание | Состояние |
|---|---|---|

| 2. Advanced Go | Struct, embedding, methods, method sets, interfaces, typed nil, errors.Is/As/Join, defer, panic/recover, generics | Следующий блок: ориентир 30 практик с Guided Coding и 300 новых вопросов |

| 4. Runtime | GMP, GC, stack/heap, escape analysis, аллокации, benchmark, pprof | Есть стартовые задачи; расширение запланировано |

Сквозные задачи продукта:

- Выстроить учебные маршруты Beginner → Junior → Middle → Senior с явными prerequisites и контрольными точками. Сейчас уровни каталога «Основа», «Работа», «Багфикс» не являются подтверждённой классификацией по грейдам.
- Расширить интерактивные визуализации внутри приложения: стек вызовов, память, slices, map, горутины, каналы и runtime. Текущие сценарии показывают пошаговые состояния; произвольные интерактивные симуляции ещё предстоят.
- Связать теорию, вопросы, ошибки, практику и интервальное повторение в единый маршрут. После ошибки предлагать 3–5 дополнительных вопросов по конкретному понятию там, где есть достаточно размеченных вопросов.
- Синхронизировать учебный прогресс между браузером, Telegram и устройствами через backend, сохраняя существующие данные.
- Развивать самостоятельное решение, разбор ошибок компиляции и задач с производственным контекстом, а затем режимы интервью и live coding. AI-интервьюер — перспективная возможность, не готовая функция.
- Долгосрочный ориентир: 2 000+ вопросов и 300+ практических задач. Это цели развития, не текущий объём и не гарантия сроков.

Каждый новый блок: теория → визуальный разбор → тесты → Guided Coding → самостоятельная практика → применение в работе → повторение. Перед публикацией — проверка учебных материалов, тестов, эталонных решений и ошибочных заготовок; после публикации — проверка браузера и Mini App, синхронизация каталога бота.

### Принцип Guided Coding

Ориентир — задачи Go Core: сначала показать алгоритм на примере, затем объяснить «Мысль → Go» строка за строкой, собрать план и заполнить пропуски, дописать почти готовую функцию, исправить ошибку и только затем решить самостоятельно. Не требовать самостоятельного написания незнакомого кода до объяснения. Подробные требования: [GUIDED-CODING.md](gym/GUIDED-CODING.md).
