# Guided Coding pilot
Dedupe only: five stages, deterministic trace, line explanations, ordering, blanks, partial/bug/starter templates, progressive hints, compiler feedback. All code submissions still use existing Go Playground runner and consent. Draft replacement requires confirmation. Other tasks unchanged except generic compiler hints and clearer hint label. Guided UI state is session-local; no mastery tracking. Related exercises are existing filter and slice-detach, not new kata. Run node gym/guided-check.cjs and node --check gym/app.js; verify on mobile before merge.

## От условия к самостоятельному коду

Начиная с версии интерфейса 17 все задачи с Guided Coding используют шесть этапов: С чего начать → Алгоритм → Мысль → Go → Собери план → Пропуски → Практика. На первом этапе ученик формулирует вход, выход, маленький пример и собственный план. Подсказка показывает первое действие без кода. На этапе «Мысль → Go» ученик пишет фрагмент для каждого действия до просмотра эталона, может скрыть его и повторить по памяти. Фрагменты и план сохраняются при навигации внутри открытого упражнения, но не между перезагрузками или устройствами. Сравнение с примером не является семантической проверкой; только существующий runner проверяет полное решение настоящими Go-тестами. При открытии заготовки подтверждение замены черновика сохраняется. Проверка на реальном телефоне и Telegram Mini App требуется отдельно.
